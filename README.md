# Student Performance Dashboard

## Day 1 - Dashboard Development

### Objective

Develop a responsive Student Performance Dashboard using HTML, CSS, JavaScript, and Chart.js to display and analyze student performance data.

### Features Implemented

#### Dashboard Summary Cards

The dashboard displays key performance metrics:

* Total Students
* Average Marks
* Highest Score
* Lowest Score

#### Performance Summary

Additional analytics were implemented to identify:

* Top Performing Student
* Bottom Performing Student

#### Student Records Table

A table was created to display student information including:

* Student ID
* Student Name
* Marks
* Grade

#### Data Visualization

Implemented interactive charts using Chart.js:

* Bar Chart to compare student marks
* Doughnut Chart to show performance distribution

#### Grade Classification

Students are automatically categorized based on marks:

* Grade A : 80 and above
* Grade B : 60 to 79
* Grade C : Below 60

#### Responsive Design

The dashboard is fully responsive and adapts to:

* Desktop Devices
* Tablets
* Mobile Devices

### Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Chart.js

### Implementation Details

* Student data is stored in a JavaScript array.
* JavaScript is used to calculate performance metrics dynamically.
* DOM manipulation is used to update dashboard cards and table contents.
* Chart.js is used for graphical representation of student performance.
* CSS Grid and Flexbox are used to create a responsive layout.

Through this task, I gained hands-on experience in:

* HTML page structuring
